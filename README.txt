CHARLIE'S COOKBOOK V7 — NO WORKFLOW PHOTO VERSION

This version does not require GitHub Actions or hidden folders.

It requests each recipe page's primary social-preview image through Microlink
when the image enters view. Images remain hosted remotely and are not copied
into this repository. If a preview cannot be retrieved, the built-in navy
category artwork appears automatically.

UPLOAD ALL:
- index.html
- styles.css
- recipes.js
- app.js
- service-worker.js
- manifest.webmanifest
- icons folder
- art folder

Replace existing files, commit, wait for GitHub Pages, then press Ctrl+Shift+R.
