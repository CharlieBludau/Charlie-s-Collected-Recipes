CHARLIE'S COOKBOOK V6 — SAFE REMOTE RECIPE PHOTOS

This version uses each source page's own Open Graph / social-preview image URL when available.
It does not download or store copies of recipe photographs in this repository.
If a source blocks, removes, or changes an image, the site falls back to built-in category artwork.

UPLOAD:
Upload every file and folder in this package, including:
- .github
- scripts
- art
- icons
- index.html, styles.css, app.js, recipes.js, recipes.json,
  previews.js, service-worker.js, and manifest.webmanifest

AFTER COMMITTING:
1. Open the repository's Actions tab.
2. Select "Refresh recipe preview images."
3. Click "Run workflow" and confirm.
4. Wait for the green checkmark.
5. The workflow commits previews.js automatically; GitHub Pages then redeploys.
6. Hard-refresh the live site with Ctrl+Shift+R.

The workflow also refreshes preview links automatically once per month.
