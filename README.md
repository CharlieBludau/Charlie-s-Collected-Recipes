# Charlie’s Collected Recipes — Version 6

## Test locally
1. Extract the ZIP.
2. Open the extracted folder.
3. Double-click `index.html`.

Keep these together:
- `index.html`
- `styles.css`
- `data.js`
- `app.js`
- `images/`

## Publish to GitHub Pages
Upload **all files and the complete images folder** to the root of the `Charlie-s-Cookbook` repository. Replace the older files.

This edition uses only relative paths such as `images/recipe-001.jpg`, and all 131 referenced images are included.

## Update
Recipe-card photos now open the original recipe link in a new tab.
